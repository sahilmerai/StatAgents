## VISUALIZATION PRINCIPLES

### Design Quality Standards

**ALWAYS apply these:**

1. **High Resolution:** dpi=300 (publication quality)
2. **Tight Layout:** bbox_inches='tight' (no clipping)
3. **Clear Labels:** Large fonts (12-14pt), descriptive titles
4. **Professional Colors:** Use color palettes, avoid default colors
5. **Grid Lines:** Alpha=0.3 for subtle grids
6. **Legends:** When multiple series, clear and positioned well
7. **Context:** Title explains WHAT, axis labels explain WHAT

### Chart Type Selection

| Data Type | Best Chart |
|-----------|------------|
| Trend over time | Line chart |
| Compare categories | Bar chart (horizontal if many categories) |
| Distribution | Histogram, box plot, violin plot |
| Relationship (2 vars) | Scatter plot |
| Relationship (many vars) | Correlation heatmap |
| Part-to-whole | Pie chart (only if ≤5 categories), stacked bar |
| Geographical | Choropleth map (if geo data available) |

### Step 3: Create Visualization

**Example: Time Series Line Chart**
```python
# Convert date if needed
df['date'] = pd.to_datetime(df['date'])

# Create figure
fig, ax = plt.subplots(figsize=(14, 7))

# Plot
ax.plot(df['date'], df['sales'], linewidth=2.5, color='steelblue', marker='o', markersize=4)

# Formatting
ax.set_title('Monthly Sales Trend (2020-2024)', fontsize=16, fontweight='bold', pad=20)
ax.set_xlabel('Date', fontsize=13)
ax.set_ylabel('Sales ($)', fontsize=13)
ax.grid(alpha=0.3, linestyle='--')

# Rotate x-axis labels
plt.xticks(rotation=45, ha='right')

# Add reference line (e.g., mean)
mean_sales = df['sales'].mean()
ax.axhline(y=mean_sales, color='red', linestyle='--', linewidth=1.5, 
           label=f'Average: ${mean_sales:,.0f}', alpha=0.7)
ax.legend(fontsize=11)

# Tight layout
plt.tight_layout()

# Save
plt.savefig('./data/Output/Plots/sales_trend_professional.png', dpi=300, bbox_inches='tight')
plt.close()

print("✓ Chart saved: ./data/Output/Plots/sales_trend_professional.png")
```

**Example: Grouped Bar Chart**
```python
# Group by category
category_sales = df.groupby('region')['sales'].sum().sort_values(ascending=True)

# Create horizontal bar chart (easier to read labels)
fig, ax = plt.subplots(figsize=(10, 6))

bars = ax.barh(category_sales.index, category_sales.values, color='skyblue', edgecolor='navy')

# Add value labels
for i, (idx, val) in enumerate(category_sales.items()):
    ax.text(val + max(category_sales) * 0.02, i, f'${val:,.0f}', 
            va='center', fontsize=11, fontweight='bold')

# Formatting
ax.set_title('Total Sales by Region', fontsize=16, fontweight='bold', pad=20)
ax.set_xlabel('Total Sales ($)', fontsize=13)
ax.set_ylabel('Region', fontsize=13)
ax.grid(axis='x', alpha=0.3)

plt.tight_layout()
plt.savefig('./data/Output/Plots/sales_by_region.png', dpi=300, bbox_inches='tight')
plt.close()

print("✓ Chart saved: ./data/Output/Plots/sales_by_region.png")
```

**Example: Correlation Heatmap**

# Select numerical columns

**Example: Multi-Panel Dashboard**
```python
# Create 2x2 dashboard
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# Panel 1: Time series
axes[0, 0].plot(df['date'], df['sales'], linewidth=2, color='steelblue')
axes[0, 0].set_title('Sales Trend', fontsize=14, fontweight='bold')
axes[0, 0].set_xlabel('Date', fontsize=11)
axes[0, 0].set_ylabel('Sales', fontsize=11)
axes[0, 0].grid(alpha=0.3)

# Panel 2: Distribution
axes[0, 1].hist(df['sales'], bins=30, color='coral', edgecolor='black', alpha=0.7)
axes[0, 1].set_title('Sales Distribution', fontsize=14, fontweight='bold')
axes[0, 1].set_xlabel('Sales', fontsize=11)
axes[0, 1].set_ylabel('Frequency', fontsize=11)
axes[0, 1].grid(alpha=0.3)

# Panel 3: Category comparison
category_means = df.groupby('region')['sales'].mean().sort_values()
axes[1, 0].barh(category_means.index, category_means.values, color='lightgreen', edgecolor='darkgreen')
axes[1, 0].set_title('Average Sales by Region', fontsize=14, fontweight='bold')
axes[1, 0].set_xlabel('Average Sales', fontsize=11)
axes[1, 0].grid(alpha=0.3)

# Panel 4: Box plot
df.boxplot(column='sales', by='region', ax=axes[1, 1])
axes[1, 1].set_title('Sales Variability by Region', fontsize=14, fontweight='bold')
axes[1, 1].set_xlabel('Region', fontsize=11)
axes[1, 1].set_ylabel('Sales', fontsize=11)
plt.sca(axes[1, 1])
plt.xticks(rotation=45)

# Overall title
fig.suptitle('Sales Dashboard - Comprehensive Overview', fontsize=18, fontweight='bold', y=0.995)

plt.tight_layout()
plt.savefig('./data/Output/Plots/sales_dashboard.png', dpi=300, bbox_inches='tight')
plt.close()

print("✓ Dashboard saved: ./data/Output/Plots/sales_dashboard.png")
```
