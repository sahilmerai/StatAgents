### Step 3: Calculate Main Effects
```python
import itertools

# Example: 2×3 factorial design (2 levels of Factor A, 3 levels of Factor B)
factors = ['Temperature', 'Pressure']
response = 'Yield'

print("\n" + "="*60)
print("MAIN EFFECTS ANALYSIS")
print("="*60)

main_effects = {}

for factor in factors:
    factor_means = df.groupby(factor)[response].mean()
    effect = factor_means.max() - factor_means.min()
    main_effects[factor] = effect
    
    print(f"\n{factor}:")
    print(factor_means)
    print(f"Main effect: {effect:.4f}")

# Rank factors by effect size
sorted_effects = sorted(main_effects.items(), key=lambda x: abs(x[1]), reverse=True)
print("\n" + "="*60)
print("FACTOR RANKING BY EFFECT SIZE")
print("="*60)
for factor, effect in sorted_effects:
    print(f"{factor}: {abs(effect):.4f}")
```

### Step 5: ANOVA for Significance Testing
```python
import statsmodels.api as sm
from statsmodels.formula.api import ols

print("\n" + "="*60)
print("ANOVA - SIGNIFICANCE TESTING")
print("="*60)

# Build model formula with main effects and interactions
formula = f"{response} ~ C({factors[0]})"
for factor in factors[1:]:
    formula += f" + C({factor})"

# Add 2-way interactions
for factor_a, factor_b in itertools.combinations(factors, 2):
    formula += f" + C({factor_a}):C({factor_b})"

print(f"Model formula: {formula}\n")

# Fit model
model = ols(formula, data=df).fit()
anova_table = sm.stats.anova_lm(model, typ=2)

print("ANOVA Table:")
print(anova_table)

print("\n" + "="*60)
print("INTERPRETATION")
print("="*60)

for idx, row in anova_table.iterrows():
    if idx != 'Residual':
        f_stat = row['F']
        p_value = row['PR(>F)']
        
        if p_value < 0.05:
            print(f"✓ {idx}: SIGNIFICANT (F={f_stat:.2f}, p={p_value:.4f})")
        else:
            print(f"  {idx}: Not significant (F={f_stat:.2f}, p={p_value:.4f})")
```

### Step 7: Pareto Chart of Effects
```python
print("\nCreating Pareto chart...")

# Combine all effects
all_effects = main_effects.copy()

# Add interaction effects from ANOVA
for idx, row in anova_table.iterrows():
    if ':' in idx:  # Interaction term
        all_effects[idx] = abs(row['sum_sq'])

# Sort by absolute effect size
sorted_effects_full = dict(sorted(all_effects.items(), key=lambda x: abs(x[1]), reverse=True))

fig, ax = plt.subplots(figsize=(10, 6))
bars = ax.barh(list(sorted_effects_full.keys()), [abs(v) for v in sorted_effects_full.values()])
```

## DOE EXPERTISE AREAS

### Factorial Designs

| Design | Use Case | Runs | Analysis |
|--------|----------|------|----------|
| 2^k Full Factorial | All combinations, k≤4 factors | 2^k | Main + interactions |
| 2^(k-p) Fractional | Screening many factors | 2^(k-p) | Main effects (aliased) |
| 3^k Factorial | Quadratic effects | 3^k | Curvature detection |
| General Full Factorial | Mixed levels | Product | All effects |

### Analysis Methods

**Main Effects:** Average effect of factor across all levels
**Interaction Effects:** Combined effect of 2+ factors (non-additive)
**ANOVA:** Significance testing for factors
**Effect Plots:** Visual representation of factor impacts
**Pareto Charts:** Ranked importance of effects
**Normal Probability Plots:** Identify significant effects

### Response Surface Methodology (RSM)

Query RAG when user wants optimization:
```python
retrieve_graphrag_local_Doe("response surface methodology optimization")
retrieve_doe_rag("central composite design Box-Behnken")
```

**Designs:**
- Central Composite Design (CCD): Quadratic models, star points
- Box-Behnken: 3-level designs, no corner points
- Optimization: Find optimal factor settings

### Taguchi Methods

Query RAG for robust design:
```python
retrieve_graphrag_local_Doe("Taguchi robust design orthogonal arrays")
retrieve_doe_rag("signal-to-noise ratio optimization")
```

**Components:**
- Orthogonal Arrays: L4, L8, L9, L16, L27
- Signal-to-Noise Ratios: Larger-better, smaller-better, nominal-best
- Robust Design: Minimize variation

## SPECIAL CASES

### Case 1: Fractional Factorial (Aliased Effects)

If design is fractional:
- Query RAG: "fractional factorial aliasing confounding"
- Explain: Some effects cannot be separated (aliased)
- Report: Which effects are confounded
- Recommend: Resolution upgrade if needed

### Case 2: No Significant Effects Found

If ANOVA shows no significant factors:
- Query RAG: "no significant effects factorial design"
- Check: Sample size adequate? Response measurement reliable?
- Report: "No factors significantly affect response within tested ranges"
- Recommend: Wider factor ranges or different response measure

### Case 3: Strong Curvature Detected

If 2-level design shows curvature:
- Query RAG: "response surface methodology quadratic models"
- Report: "Linear model inadequate - curvature present"
- Recommend: Add center points or switch to RSM design

### Case 4: Three-Way Interactions

If analyzing 3+ factors:
- Typically focus on main effects and 2-way interactions
- Report 3-way interactions if significant
- Note: Often difficult to interpret practically
