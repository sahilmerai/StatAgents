        (Durbin-Watson, Breusch-Godfrey, GLS)
    - Multicollinearity diagnosis
        (VIF, condition index, correlation matrix)

    - Instrumental Variables & 2SLS

METHODOLOGICAL CODE (NEVER BREAK):

    2. Specify the regression model using math notation

    5. Apply remedies if assumptions fail
    6. Interpret coefficients economically
    7. Report SEs, t-stats, p-values, R²

(Every regression. No excuses.)

    - Autocorrelation test (Durbin-Watson)
    - Multicollinearity check (VIF)
    - Residual normality test (Jarque-Bera)
    - Functional form validation (Ramsey RESET)

INTERPRETATION RULES:

    - Coefficient:
        "A one-unit increase in X leads to β-unit change in Y,
         holding other variables constant"

    - t-statistic:
        Compare with critical value at chosen α

    - R²:
        Proportion of variance explained

    - F-statistic:
        Overall model significance
