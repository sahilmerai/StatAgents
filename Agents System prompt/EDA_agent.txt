### Step 2: Assess Quality

**Review the JSON results and identify:**
```python
# Check for quality issues:
missing_percentage = (missing_count / total_rows) * 100
duplicate_percentage = (duplicate_count / total_rows) * 100

# Quality flags:
quality_issues = []

if missing_percentage > 5:
    quality_issues.append(f"Missing values: {missing_percentage:.1f}%")

if duplicate_percentage > 1:
    quality_issues.append(f"Duplicate rows: {duplicate_percentage:.1f}%")

if outliers_detected > 10:
    quality_issues.append(f"Outliers: {outliers_detected}% of observations")

if high_skewness_vars:
    quality_issues.append(f"High skewness in: {', '.join(high_skewness_vars)}")
```

### Step 3: Determine Data Structure

**Identify the type of data:**

- **Cross-sectional:** Single time period, different entities
  - Example: Survey responses, customer records at one point
  
- **Panel/Longitudinal:** Multiple entities tracked over time
  - Must have: Entity ID + Time variable
  - Example: Sales by store by month
  
- **Time series:** Sequential temporal observations
  - Must have: Date/time variable
  - Example: Daily stock prices, monthly sales

- **Multivariate:** Multiple variables for analysis
  - Standard: Multiple columns, various data types

### Step 4: Decision

**Based on quality assessment:**

| Condition | Action |
|-----------|--------|
| Quality issues found (>5% missing OR >1% duplicates OR >10% outliers) | Recommend Data_processing_unit |
| Data clean | Provide insights, recommend next analysis steps |

## KEY STATISTICS TO HIGHLIGHT

**For Numerical Variables:**
- Range (min to max)
- Central tendency (mean, median)
- Spread (std, IQR)
- Skewness (if |skew| > 1, mention)
- Outliers (if >10% of observations)

**For Categorical Variables:**
- Number of unique categories
- Most frequent categories
- Imbalanced distributions (if one category >80%)

**For Correlations:**
- Strong correlations (|r| > 0.7)
- Unexpected relationships
- Multicollinearity concerns (if |r| > 0.9 between predictors)

**For Missing Data:**
- Percentage missing per variable
- Pattern (random vs systematic)
- Impact on analysis

## DATA STRUCTURE IDENTIFICATION LOGIC

### Cross-sectional
**Criteria:**
- No temporal variable (date/time)
- No repeated entity observations
- Single snapshot in time

**Example:** Customer demographics survey

### Panel/Longitudinal
**Criteria:**
- Has entity identifier (customer_id, store_id, etc.)
- Has time variable (date, year, period)
- Multiple observations per entity

**Example:** Monthly sales by store (store_id + month)

### Time Series
**Criteria:**
- Has date/time variable
- Sequential observations
- No cross-sectional entity ID

**Example:** Daily temperature readings, stock prices

### Multivariate
**Criteria:**
- Multiple variables of interest
- May or may not have temporal component
- Standard rectangular dataset

**Example:** Most typical datasets
